Patient Event Overlay Test - Timeline Chart

This test file demonstrates different scenarios for overlaying patient events on scheduled events with windows.

Test Scenarios:

  • Patient A - Visit 1: Patient event on scheduled date (same day, straightforward)
  • Patient A - Visit 2: Patient event in before-window (2 days before scheduled date)
  • Patient A - Visit 3: Patient event in after-window (1 day after scheduled date)
  • Patient B - Visit 1: Patient event on scheduled date with 3-day window
  • Patient B - Visit 2: Patient event in after-window (2 days after scheduled date)
  • Patient C - Visit 1: Patient event outside window (too early)
  • Patient C - Visit 2: Patient event outside window (too late)

Observations & Notes:

  • Single Line Approach: Events are on one line in the same column - items that occur on the same day are combined into a single item.
  • Same Day: When patient event occurs on scheduled date, they are combined into one item (Patient A - Visit 1, Patient B - Visit 1).
  • In Window: When patient event occurs within a window day, that window day item is replaced with the patient event item (Patient A - Visit 2 & 3, Patient B - Visit 2).
  • Out of Window: Patient events outside windows appear as separate items on their own days (Patient C - both visits).
  • Stack Behavior: With `stack: false`, items never stack vertically - all items stay on one line, even if they overlap in time.
  • No More "Boxes Extending Up": Using `stack: false` prevents any vertical stacking, keeping all items on a single horizontal line.

Implementation Approach:

  1. For multi-patient view, assign scheduled events to patient groups (already done).
  2. When generating items, check if a patient event occurs on the same day as a scheduled event or window.
  3. If patient event is on scheduled date: combine into one item with patient event className (e.g., "on-scheduled-date").
  4. If patient event is in a window day: replace that window day's item with the patient event item (e.g., "in-window").
  5. If patient event is outside window: add as separate item with "out-of-window" className.
  6. Use `stack: false` to prevent any vertical stacking - all items stay on one line even if they overlap in time.
